## Notes

- `google/adk-kotlin` 星标仅 201，但是 Google 官方 Android/KMP Agent SDK。1.0.1 之后 main 已合入 MCP reject 保活和 `Plugin.onRunError`，下一轮盯 1.0.2。
- `android/appfunctions`（189★，2026-05 建仓）是官方 AppFunctions 样品 + Testing Agent。官方文档把 AppFunctions 写成「Android 上的 MCP 等价物」。按真实工程价值列为 P0。
- `android/skills` 已含 `device-ai/appfunctions` skill（Discovery / Implementation / KDoc / ADB 测试）。
- `slackhq/compose-lints` 1.6.0（2026-08-27）是基线漏收的 Slack 生产 Compose lint，本轮补入 P1。
- Circuit 已跟到 Compose 1.12.1 + Benchmark 1.5.0；Foundry 构建基线仍是 AGP 9.3.1 / Gradle 9.6.1 / Kotlin 2.4.10。
- Dagger 文档已写明：KSP 支持自 Dagger 2.60+ / KSP 2.3.9+ 起视为稳定。
- ktlint 已迁到 `ktlint/ktlint`；Store 已迁到 `MobileNativeFoundation/Store`。
- Flipper、AffectedModuleDetector 已 archived / 迁移，只做 Inactive 跟踪。
- Netflix / Pinterest 除 ktlint 外，本轮仍无新的 Android 工程向开源动作。
