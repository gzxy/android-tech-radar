- lynxtron 星标极低（30），但是 Lynx 2026 Roadmap 明确的桌面/Electron 方向，作为生态信号保留。
- 华为 / 百度 / 网易 / 京东 2026-09-11 再扫：HMS-Core 仍是 Kit demo；百度开源主线在 vLLM-Kunlun / OCR / 云端 Agent；网易 `NetEase/skills` 是通用 agent skills（2026-03 后无推送）；京东 JoyAI / OxyGent / Taro 不是 Android 工程仓库。仍不强制填表。
