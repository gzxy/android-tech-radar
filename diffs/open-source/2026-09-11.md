## Architecture / Performance / Compatibility

- **AppFunctions = 端上 MCP。** 官方文档（Last updated 2026-09-08）写明：AppFunctions 是 MCP tool 的移动等价物，Android 16+，Jetpack `androidx.appfunctions:1.0.0-alpha10`，`@AppFunctionServiceEntryPoint` 架构。Gemini 对接仍是 private preview / EAP。
- **ADK 进程内 Agent vs AppFunctions 系统级 Tool：** 前者把 Agent 跑进 App；后者让 App 被系统 Agent / Gemini 调用。两者互补，不要混成一个 PoC。
- MNN 端侧 TTS（Qwen3-TTS talker）是性能/能力扩展，不是 Android API 变化。
- Lynx TransferView 是嵌入式宿主 API，尚未进 4.1.0 release notes。
- Kuikly Compose DSL 正式发版、Lynx 4.2：本轮仍未出现。
