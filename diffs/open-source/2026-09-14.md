## Architecture / Performance / Compatibility

- **ADK 进程内 Agent 现在官方消费 AppFunctions。** 09-11 把两条线拆开：自己跑 Agent（ADK `@Tool` / MCP Toolset）vs 被系统 Agent 调（AppFunctions）。09-11 之后 Google 在 ADK 里加了第三条用法：同一套 `@AppFunction` 给自己的 `LlmAgent` 当 tool。系统 Gemini 路径仍是 EAP。PoC 应从「两套重复能力」改成「函数写一次，ADK Toolset 先自测」。
- **AppFunctions Jetpack 地板是 alpha11。** ADK 和官方样品都按 `AppFunctionState` / `observeAppFunctions` / `ExecuteAppFunctionRequest` 写。还停在 alpha10 的样品/文档不要当实现规范。
- **遗产路由开始补 KSP2。** ARouter 2020 的 1.5.1 没发版，但 develop 用独立 Gradle 9.5 工程交出 KSP 编译器，并跑 AGP 8.12 / 9.0 / 9.3.2。叠加 09-11 Dagger「KSP 已稳定」：kapt 退役不再只发生在新库。
- **CMP 1.13 Android min 24。** 和 Now in Android / Circuit 的 compileSdk 37 不是同一件事——这是 KMP Android target 的下限。
- Lynx TransferView / 4.2：本轮仍未发版。4.0.3 不能当成 4.2 信号。
- Kuikly Compose DSL 正式发版：仍未出现。
