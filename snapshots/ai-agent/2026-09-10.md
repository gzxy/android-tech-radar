## as-quail2-agent

- 产品：Android Studio Quail 2 Stable（2026-07-16 起生产可用）
- Agent Mode 可并行多 Tab，不同 Tab 可用不同模型；无 worktree，同文件并发会冲突。
- App Quality Insights 与 Agent Mode 打通：Crash 摘要 → See more → Fix with AI → 出计划 → 人批准后改仓库并声称 verify。
- Profiler 一等集成 LeakCanary：桌面端分析（官方称最高约 5x），Go to declaration + Fix with Agent（解绑 listener / 清 static 等）。
- 模型可选 Gemini / GPT / Claude / 本地 Gemma 4；Google AI Pro/Ultra 提高 Agent 会话配额。
- 文档仍保留旧路径：AQI Insights → Suggest a fix（2026-03-06），与 Quail 2 的 Fix with AI 并存。
- ANR：AQI 可过滤 ANR，但「Fix with AI」叙事以 Crash 为主；ANR 根因（主线程卡顿、锁、binder）verify 弱于 Crash。

## crashlytics-mcp

- 状态：Experimental（无 SLA），文档 Last updated 2026-09-09。
- 入口：`npx firebase-tools@latest mcp`；Cursor Marketplace 插件可同时带 Agent Skills。
- 引导工作流：`/crashlytics:connect`（优先 / 诊断修复）。
- 工具：`crashlytics_get_issue` / `list_events` / `batch_get_events` / `get_report` / `create_note` / `update_issue` 等。
- 客户端：Cursor、Claude Code（官方 plugin）、Gemini CLI、Antigravity、Copilot、Windsurf、Cline。
- 闭环：拉 stacktrace + 用户数 → 读本地仓库 → 改代码 → 回写 note / close issue。测试步骤取决于 Agent 是否接 Gradle / Android CLI。
- 限制：需已接入 Crashlytics；依赖探测失败时用 `--only crashlytics`；Firebase 不收费，费用在 Agent 侧。

## journeys

- Studio Labs Preview；官方页 Last updated 2026-08-31。
- 自然语言步骤（XML）→ Gemini 看截图 → tap/type/swipe → 断言 → 结果面板给 reasoning。
- 运行：Studio 或 Android CLI；可进 CI/CD（需 ADB 可达设备）。Firebase Test Lab 不在官方支持叙述中。
- 要求：AGP 9.0+（可用预装 app + `JOURNEYS_CUSTOM_APP_ID` 绕过业务工程升级）。
- 不完整：多指、长按、双击、旋转/折叠、跨步记忆、计数、条件分支。
- 已知问题：Gradle configuration cache 可能导致跑错 journey / 鉴权问题。
- 闭环停在「测」，不自动改业务代码。

## maestro-mcp

- `maestro mcp` 内置于 Maestro CLI；Claude / Cursor / Codex / Gemini / Copilot 一等安装说明。
- Agent：list devices → inspect hierarchy → 写 YAML flow → run → 失败自修 → 文件入库供 CI。
- 产物是人可读 YAML，不是一次性聊天。
- 本地模拟器/真机；Maestro Cloud 为规模化付费层。
- 与 Journeys 差异：Journeys 每次推理、抗 UI 微调；Maestro 生成后走确定性脚本，CI 成本更可控。

## cursor-bugbot

- 自动审 PR；`cursor review` / `bugbot run`；`/review`、`/review-bugbot`（Cursor 3.7+，推前）。
- Autofix 可拉起 Cloud Agent 修审出的问题。
- 规则：`.cursor/BUGBOT.md`（项目规则不自动生效）。
- Check 名 `Cursor Bugbot`；发现默认 `neutral`，需显式 fail-on-unresolved 才挡合并。
- 无 Android 专用规则；Compose / 生命周期 / 线程误用依赖自定义 BUGBOT.md + skills。
- 2026-06 官方称均审约 90s（厂商数据）。

## cursor-cloud-agent

- 读仓库、改代码、跑命令、开 PR；Scheduled / Repository / Automation Agent 可用。
- Android 模拟器进 Cloud Agent：团队内有过手写指令实验，**无正式无手扶能力，无日期**。
- 实用边界：`./gradlew test`、lint、依赖/文档/Crash 修（配 MCP）；Instrumented / UI / ANR 复现不闭环。
- 本机 sidecar：Cursor Agent Window + Android Studio（ACP / IntelliJ MCP / debugger MCP）。

## github-aw

- GitHub Agentic Workflows：自然语言 Markdown → Actions；引擎 Copilot CLI / Claude Code / Codex。
- 2026-06-11 起可用 `GITHUB_TOKEN`，不必再为 Agent 工作流存 PAT。
- 已有 Android 个例：Dependabot 级联升级导致 CI 红 → 分析瞬时/永久失败 → 验证 `./gradlew` → 开修复 PR。
- 边界：适合编译/单测/依赖；不覆盖 Crash/ANR/真机。

## gbox-mcp / androidbuild-mcp / gradle-mcp

- GBOX：云 VM 或本地设备 MCP（需 API Key）。
- AndroidBuildMCP：`build_app` 压缩 Gradle 错误、emulator、adb、logcat、UI automation。
- Gradle Tooling API MCP：解析后项目模型，回答「依赖为何解析失败」。
- 均为社区/商业拼装层，未达官方技能库的可维护性。
